# Four poker kings

Generated with the built-in imagegen tool from the provisional King of Spades and the supplied back pattern references. The complete prompt sequence is in [poker-kings-prompts.md](poker-kings-prompts.md); historical paths inside those prompts identify the inputs used at generation time.

The four current masters live under `cards/faces/french-suited/poker/<suit>/king.png`. Their original `v1` designation is preserved in the import map; subsequent current revisions are tracked by Git.

## Shared design
- Warm ivory, antique gold, muted olive foliage, navy/madder clothing and dark floral field.
- Reduced figure scale and continuous rectangular beaded border.
- Black indices on Clubs/Spades and red indices on Diamonds/Hearts.
- Each face works with every poker back color.

## Current checks and limits
All four masters are 1060 × 1484, exactly 5:7. Their intended trim is 2.5 × 3.5 inches, independent of 96-DPI image metadata. No resampling or image editing was performed during repository setup.

These are visually coordinated review masters. Repeated flower details and half-turn portraits are not mathematically identical. The smaller figure was generated from an approximately 13% reduction request, not a measured scaling operation. Exact shared ornament plates and exact opposing halves remain production refinements.

Spades: broadsword, both eyes visible, slight rightward turn. Hearts: sword behind head, clean upper lip, jaw/chin beard. Diamonds: left profile, one eye, axe. Clubs: left three-quarter view, sword and cross-topped orb.

The reference text combines Paris-pattern historical names with English-pattern visual conventions. We retained the requested recognizable visual attributes without adding historical names to the cards.
