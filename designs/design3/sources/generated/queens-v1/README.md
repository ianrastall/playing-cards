# Celtic Queen masters — first review set

Built-in ImageGen created these four selected masters. Each file is preserved
unchanged, before registration to the approved Kings' common layout.

- [Spades](queen-spades-v1.png)
- [Hearts](queen-hearts-v1.png)
- [Diamonds](queen-diamonds-v1.png)
- [Clubs](queen-clubs-v1.png)

[manifest.json](manifest.json) records selected hashes and dimensions.
[prompts.json](prompts.json) records every exact generation and correction prompt
and its reference paths. Hearts, Diamonds and Clubs also retain an `initial`
pass for provenance; these are not selected or exposed in the card viewer.

The first reference was the rugged Celtic Spades King. Design 1 Queens supplied
pose and attribute references only. These new Queens are artwork for review.
Their [balanced preview](../../../queens.html) uses the Kings' established border
and center. See the [design notes](../../../docs/design/queens-v1.md).
