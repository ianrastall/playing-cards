# Celtic Poker Joker masters

Built-in ImageGen created two selected, unchanged paintings:
[Black Joker](joker-black-v1.png), a storyteller with a carved fool's staff,
and [Red Joker](joker-red-v1.png), a woman bard with a small wooden harp.

The Celtic Spades Queen supplied style; existing Design 1 Jokers supplied the
double-ended entertainer structure and stacked index layout only. Props and
clothing are fictional artistic cues. Both were generated in one pass.
[manifest.json](manifest.json) records dimensions, SHA-256 hashes and exact
`joker-<color>-prompt.json` records.
