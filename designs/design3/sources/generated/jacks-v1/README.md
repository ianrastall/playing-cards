# Celtic Poker Jack masters

Built-in ImageGen created four selected, unchanged paintings:
[Spades](jack-spades-v1.png), [Hearts](jack-hearts-v1.png),
[Diamonds](jack-diamonds-v1.png) and [Clubs](jack-clubs-v1.png).

The Celtic Spades Queen supplied style; the existing Design 1 Jacks supplied
head directions, eye counts, hand poses and attributes only.
[manifest.json](manifest.json) records dimensions, SHA-256 hashes and each exact
`jack-<suit>-prompt.json` record. Each painting was generated in one pass.
