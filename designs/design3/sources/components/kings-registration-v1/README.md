# Celtic Kings production components

These deterministic components derive from the approved Spades painting.
They supply a shared painted Celtic frame, the compositing field mask, one
centered half-turn-safe double spiral, a rotated pair of side triskeles, and
consistent K/French suit indices. The outline mask reproduces the collection's
established Poker 3.5 mm rounded corners.

The indices use Times New Roman Bold. Black and red ink share identical positions;
the rest of the cream index panel belongs to the shared frame.

The [registration script](../../../scripts/register_kings.py) builds these files
from immutable masters. Component and source hashes are recorded in the
[release manifest](../../../docs/design/kings-registration-v1.json).
