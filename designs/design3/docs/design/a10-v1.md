# Celtic Poker A–10 — first assembled set

Forty faces are ready for review in the [A–10 viewer](../../a-10.html).
Each is a 750 × 1050 RGBA PNG at 300 ppi, with the Kings' existing border,
index reserves and 3.5 mm rounded alpha corners. The four generated pip
masters remain unchanged. New cards have catalog status `review`; the four
Kings retain status `approved`.

The court figure field is replaced with a symmetric cream reserve. The field
follows each index panel's painted rim and lower leaf, clearing the navy and
woodland remnants previously retained by a rectangular court-field exclusion.
The cream panel also clears residual original index ink. The repair mask is
recorded separately; other frame pixels retain the shared court frame exactly. A/suit and numeral/suit
indices use the court font and positions, with an exact rotated lower partner.

Each suit's painted central medallion supplies its registration point. A circle
fit to its gold rim estimates that point; it is not assumed to be the image's
midpoint or alpha centroid. Separate working copies remove disconnected alpha
residue, normalize the nearly opaque body and crop transparent margins.
Uniform scaling preserves each silhouette. Within a rank, all four medallions
have the same fitted rim radius and are registered to the same layout anchors.
The untouched masters and the transforms are recorded in the
[assembly manifest](a10-v1.json).

The card center is **(374.5, 524.5)**. Layouts follow the earlier designs:

| Ranks | Rotation rule |
| --- | --- |
| 2, 4, 6, 8, 10 | Every pip has an exact 180° counterpart; the complete image is reversible. |
| A, 3, 5, 7, 9 | One center pip stays upright; every other pip has a rotated counterpart. |

The six and seven pair their two side pips across the horizontal center line.
The seven adds a single upright center pip. The nine uses a three-by-three
arrangement with the same pairing rule. The ten uses two four-pip columns and
two paired inner pips. Artwork inside a pip is directional, including Diamonds,
so the odd ranks intentionally have a center-only half-turn exception.

The [audit](a10-v1-audit.json) checks all forty final images: visible pip counts,
safe margins, no overlaps, central registration, rotated pairs, exact corner
alpha, native dimensions and density, reconstruction, and unchanged prior
artwork. It verifies twenty exact half-turn images and twenty images whose
differences are confined to the single center pip. All four suit proofs were
also visually inspected.

From the repository root:

```text
python designs/design3/scripts/build_a10.py --check
node scripts/test_gallery_filters.js
```

To rebuild, run the script without flags to stage and audit, then `--apply`
to install the staged cards. Installation only replaces a card matching its
recorded previous version or the audited new stage. Work files are ignored; components, manifests and proofs are
kept for review. No release archive is produced by this script.
