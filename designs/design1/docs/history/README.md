# Imported history

These records describe the pre-repository layout and are retained as provenance:
- `migration.json`: original and new relative paths, with SHA-256 hashes at import.
- `imported-archive-readme.md`: old archive documentation, including an earlier ten-color inventory.
- `imported-backs-validation.json`: the historical 60-back report.
- `imported-tree.txt`: supplied tree snapshot.

Historical paths and inventory statements are preserved verbatim and may no longer resolve. Use the root README, deck.json and catalog.json for current information. The recoloring script was adapted after the hash-verified import; its import hash therefore describes the earlier script, not its current bytes.
