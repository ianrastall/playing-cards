# Design 2 Minchiate source masters

Three original built-in ImageGen outputs for the first Poker review:

- `the-empress.png`: upright Empress with lotus scepter and Venus shield.
- `queen-of-cups.png`: upright seated Queen with one open chalice.
- `sword-straight.png`: reusable straight sword for Ace and counted pips.

`prompts.json` contains the exact prompts, reference paths and hashes, output
hashes, dimensions and generation method. These sources preserve their RGBA
transparency and have not been repainted or resized. The compositor measures
alpha bounds to place them inside the shared native Poker frames.

These are draft illustrations, not user-approved finished artwork.
See [the first proofs](../../../minchiate-review.html) and
[construction notes](../../../docs/design/minchiate-poker-v1.md).
