# Approved Design 2 gold-panel masters

`poker-master.png` is the selected gold-band version. The five approved color
references are retained in `approved-palette-references/`. `bridge-master.png`,
`travel-master.png`, `jumbo-master.png` and `tarot-master.png` were independently
reconfigured with built-in ImageGen, not resized from Poker.

`prompts.json` contains the exact format-generation prompts. Requested dimensions
describe the intended boxes; actual generator canvas sizes and uniform sampling
scales are recorded in the release manifest. `approved-palette-prompts.json`
preserves approval-stage prompt history. References to dark-field v1/v2 inputs
are historical: those intermediate studies were discarded after approval.

European Standard has no independently generated master; it enlarges Bridge.
The exporter uses one shared artwork plate per format and separate border/field
masks so palette variants cannot shift the artwork.

Use [the main gallery](../../../index.html) to view the finished registered PNGs.
