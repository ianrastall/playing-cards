# Design 2 silk back color masters

The selected master is `../design2-v2/silk-cinnabar-jade.png`, the final silk
proof with the radial circular center. The user selected this design and
accepted its current density, with a denser version only a future possibility.

Five individual colorways: Prussian Blue, Verdigris, Madder Lake, Manganese
Violet, and Lamp Black. The foliage, stems, medallion grounds, and perimeter
rules carry the named pigment. Red-and-ivory flowers and ochre details remain
visually consistent across the set. Palette names are digital interpretations.

Open `index.html` for a responsive comparison or each named PNG directly.
All five files were created using the built-in image-generation editing tool,
each directly from the selected master. Exact prompts are in `prompts.json`.
No density or compositional redesign was requested. Small generated variations
remain; these are not deterministic pixel-for-pixel recolors.

These 1060 x 1484 RGB files are artwork masters, outside the active Design 1
catalog. Visual checks confirmed the circular center, outer floral frame,
complete composition, and intended colors. `validation.json` records hashes,
dimensions, and measured half-turn equality. Production derivatives still
require exact symmetry, ground normalization to #FAEBD7, native card sizes,
and the collection's 3.5 mm alpha corner mask. No Design 1 assets were replaced.
