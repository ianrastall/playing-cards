# Reusable Design 2 face frames

Each format has Lamp Black and Madder Lake RGBA templates plus independent
field, index-panel, palette and outline masks. They contain no finished card
content. See [construction and usage](../../../docs/design/face-frames-v1.md)
and [manifest.json](manifest.json) for geometry and provenance.

Rebuild from the repository root with
`node designs/design2/scripts/build_face_frames.mjs`; verify with
`python designs/design2/scripts/audit_face_frames.py`.
