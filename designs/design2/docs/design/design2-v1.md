# Design 2: Chinese porcelain prototype

This is a prototype, outside the active Design 1 catalog. It was created with
the built-in image-generation tool. The original generated pixels are retained
in `sources/generated/design2-v1/cobalt-lotus-back-prototype.png`.
The exact prompt is saved alongside it in `prompts.json`.

The direction is specifically Chinese: Ming lotus-scroll ornament as the main
language, a secondary Tang floral influence, and the refinement requested for
an eighteenth-century imperial collection. It is an original contemporary
interpretation, not a claim of historical reconstruction.

Reference anchors:

- [National Palace Museum: Yongle Ming lotus meiping](https://digitalarchive.npm.gov.tw/Collection/Detail/36090?dep=U), for blue-and-white lotus ornament and ruled decorative zones.
- [Walters: Qianlong-period flask](https://art.thewalters.org/object/49.2015/), for the subtle range of cobalt brushwork on eighteenth-century porcelain.

The first proof establishes cobalt washes, a porcelain-white ground, fine
floral drawing, and a restrained ruled perimeter. It is still an exploratory
back. The scrolling leaves remain more generalized than the historical
references; the next refinement should emphasize distinctive Chinese lotus
leaf forms and less Western-looking foliate scrollwork.

Generated symmetry is approximate. It has not been promoted, labeled as
print-ready, or substituted for any Design 1 card. A production version must
use a registered component layout with verified half-turn symmetry, correct
trim dimensions, and the collection's physical corner mask.

A second built-in image-generation pass, `cobalt-lotus-back-refined.png`, uses
the museum's Yongle meiping photograph directly as a style reference. It
reduces broad foliage, introduces finer scrolling stems, and replaces the
elongated reserve with a smaller roundel. This is the preferred exploratory
proof. The central lotus remains directional, so it still needs a true
two-way component construction before use as a playing-card back. Both
versions and both exact prompts are preserved for comparison.
